# سجل الجيم
1. Firebase Console: فعّل Authentication (Email/Password) و Firestore، وأضف الحسابين يدوياً.
2. ضع بيانات المشروع في firebase-config.js.
3. جرّب محلياً: `npx serve .`  — أو انشر: `firebase login && firebase init` (اختر المشروع) ثم `firebase deploy`.
4. أول دخول يحتاج إنترنت، وبعدها يعمل أوفلاين ويزامن تلقائياً.
